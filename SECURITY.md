# Security Policy

## Supported Versions
As this is an active research project (May 29 - June 14, 2026), we only provide security updates for the current main branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within this IDS (e.g., a buffer overflow in the bit-slicing logic or a bypass of the entropy engine), please do not open a public Issue. 

Instead, please report it privately by:
1. Sending an [email](bijanvkspv@gmail.com).
2. Providing a detailed description of the vulnerability.
3. Including the specific 32-bit ARINC word or bitstream that triggers the issue.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Our Commitment
Because this project deals with avionics safety-critical protocols, we take all reports seriously. We follow the principle of **Coordinated Vulnerability Disclosure** to ensure that any flaws are patched before they are made public.
